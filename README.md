# BridgeCrossingApp

Учебная среда «Изыскания и проектирование мостовых переходов» (кафедра ТСиДМС СПбГАСУ). Модули связаны общим форматом варианта задания (JSON); на каждом этапе есть выгрузка в редактируемые форматы (Excel с формулами, CSV, JSON).

**Цепочка модулей:** Журнал работы студентов → Варианты проекта → Расчёт уровня воды → Определение отверстия моста → Проектирование регуляционных сооружений → Вариантное проектирование моста.

## Этап 1 — Генератор задания (`apps/generator/`)

Откройте `index.html` (двойным щелчком или через GitHub Pages). Сборка и интернет не нужны.

| Вкладка | Что делает (пункты видения) |
|---|---|
| Задание и ТЗ | Титульные сведения; дорога: категория, полосы, отметки ПЧ, ответственность, район; судоходство; характерные точки оси дороги на подходах (п. 14–16) |
| Геодезия | Шаги нивелировки и промеров, ширины зон → число створов и контрольные цифры; УНМ; уровень на дату изысканий; генератор профиля; рисование мышью; таблица с глубинами (п. 1–3, 6) |
| Геология | ИГУ из библиотеки 44 грунтов, генератор слоёв и линз, рисование кровель (п. 4) |
| Гидрология | Пост: ноль (по умолчанию УНМ − 2 м), удаление от оси, число лет, min/max УВВ; ВИУ как превышение над объектом; уклон числом или задачей; ландшафт и m; тип реки → годовые графики; таблица превышений; таблица для РСУ при прекращении навигации на t суток; ветер (п. 5, 7–13) |
| Топография | Квадратная топоповерхность по профилю с радиусом кривизны реки; облако точек CSV (п. 17) |
| Проверка | Ошибки и предупреждения по разделам |
| Бланк и экспорт | Бланк задания в формате примера 1/26-c; Excel (бланк + ключ преподавателя с формулами + суточные уровни + столбец старой книги для 71 створа); печать/PDF (п. 18) |
| Шаблоны | Всё задание или разделы (геодезия, гидрометеорология, геология, ТЗ) под уникальными именами |

Кнопка «Заполнить пустое» генерирует всё, что не задал преподаватель. «Новый вариант» перегенерирует профиль, грунты и ряды по новому зерну.
