# BridgeCrossingApp

Учебная среда «Изыскания и проектирование мостовых переходов» (кафедра ТСиДМС СПбГАСУ). Модули связаны общим форматом варианта задания (JSON); на каждом этапе есть выгрузка в редактируемые форматы (Excel с формулами, CSV, JSON).

**Цепочка модулей:** Журнал работы студентов → Варианты проекта → Расчёт уровня воды → Определение отверстия моста → Проектирование регуляционных сооружений → Вариантное проектирование моста.

## Этап 1 — Генератор задания (`apps/generator/`)

Откройте `index.html` (двойным щелчком или через GitHub Pages). Сборка и интернет не нужны.

| Вкладка | Что делает (пункты видения) |
|---|---|
| Задание | Сведения о задании и техническое задание: дорога, ответственность, район, судоходство (п. 14–15) |
| Рельеф | Пять зон: берега, поймы, русло — ширина и шаг, число створов и контрольные цифры; УНМ; уровень на дату изысканий; ось дороги на берегах; генератор и рисование профиля (п. 1–3, 6, 16) |
| Грунты | ИГУ из справочника 44 грунтов, генератор слоёв и линз, рисование кровель (п. 4) |
| Гидрология | Водомерный пост, min и max УВВ, ВИУ над объектом, уклон числом или задачей, ландшафт и m, тип реки → годовые графики, таблица превышений, таблица для РСУ, ветер (п. 5, 7–13) |
| Топография | Топоповерхность по профилю с радиусом изгиба реки, облако точек CSV (п. 17) |
| Выдача | Проверка; бланк Excel (+ ключ с формулами, суточные уровни); печать и PDF; книга данных; JSON (п. 18) |
| Шаблоны | Всё задание или разделы под уникальными именами |

**Вариант можно подготовить вне программы**: JSON по схеме [`schema/variant.schema.json`](schema/variant.schema.json) или книга данных Excel. Загрузка — кнопкой «Открыть». Незаполненное генерируется. Подробнее — [docs/VARIANT_FORMAT.md](docs/VARIANT_FORMAT.md).
