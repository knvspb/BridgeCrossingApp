# BridgeCrossingApp

Учебная среда «Изыскания и проектирование мостовых переходов» (кафедра ТСиДМС СПбГАСУ). Модули связаны общим форматом варианта задания (JSON); на каждом этапе есть выгрузка в редактируемые форматы (Excel с формулами, CSV, JSON).

**Цепочка модулей:** Журнал работы студентов → Варианты проекта → Расчёт уровня воды → Определение отверстия моста → Проектирование регуляционных сооружений → Вариантное проектирование моста.

## Этап 1 — Генератор задания (`apps/generator/`)

Откройте `index.html` (двойным щелчком или через GitHub Pages). Сборка и интернет не нужны.

Вкладки идут в порядке плана генератора (пункты 1–18):

| Вкладка | Пункты |
|---|---|
| 1–3 Профиль | 1 — шаги нивелировки (берега, поймы) и промеров, ширины зон → створы и контрольные цифры; 2 — УНМ; 3 — профиль дна (рисование, таблица, генератор), точность 0,1 м |
| 4 Грунты | Границы ИГУ (рисование, генератор) и описание грунтов из библиотеки |
| 5–8 Изыскания | 5 — морфометрия (ландшафт, m) и уклон (числом или задачей); 6 — промеры глубин от уровня на дату изысканий; 7 — ВИУ, год, превышение над известным объектом; 8 — водпост: число лет, перенос на ось, нуль (УНМ − 2 м), min и max УВВ → превышения |
| 9–12 Ряды | 9 — тип реки; 10 — годовые графики уровней; 11 — таблица превышений; 12 — таблица для РСУ (уровень без N суток с наивысшими уровнями) |
| 13–14 | Ветер; судоходство |
| 15–16 Дорога | 15 — категория, состав, район, ответственность; 16 — характерные точки оси дороги на берегах |
| 17 Топография | Топоповерхность с радиусом изгиба реки, облако точек CSV |
| 18 Бланк | Шапка бланка, проверка, Excel (+ ключ с формулами, суточные уровни), печать и PDF, книга данных, JSON |
| Шаблоны | Всё задание или разделы: геодезия, гидрометеорология, геология, ТЗ |

Незаполненное генерируется автоматически; «🎲 Новый» — новый вариант по новому зерну.

**Вариант можно подготовить вне программы**: JSON по схеме [`schema/variant.schema.json`](schema/variant.schema.json) или книга данных Excel. Загрузка — кнопкой «Открыть». Незаполненное генерируется. Подробнее — [docs/VARIANT_FORMAT.md](docs/VARIANT_FORMAT.md).
