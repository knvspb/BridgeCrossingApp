BridgeCrossingApp

Изыскания и проектирование мостовых переходов — учебная среда. Модули связаны общим форматом варианта задания; на каждом этапе есть выгрузка в Excel.

  1. Генератор задания
    Профиль, промеры, ИГУ, гидрология и навигация, ТЗ, топоповерхность; бланк задания и Excel
    готов (этап 1)
  2. Журнал работы студентов
    Выдача вариантов, контрольные сроки, автопроверка по ключу
    планируется
  3. Варианты проекта
    Пакетная генерация по зерну для группы
    планируется
  4. Расчёт уровня воды
    Ряд УВВ, статистика, Qp, расчётный уровень, РСУ
    планируется
  5. Определение отверстия моста
    Общий размыв, проверка грунтов, минимальное отверстие
    планируется
  6. Проектирование регуляционных сооружений
    Струенаправляющие дамбы
    планируется
  7. Вариантное проектирование моста
    Схемы моста, сравнение вариантов
    планируется
