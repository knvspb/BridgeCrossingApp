# Формат данных варианта

Вариант задания можно сформировать вне программы и загрузить кнопкой «Открыть». Возможные источники: Excel, другая программа, нейросеть. Поддерживаются два формата.

## 1. JSON

Формат описан схемой [`schema/variant.schema.json`](../schema/variant.schema.json) (JSON Schema 2020-12, описания полей на русском).

**Минимальный вариант** — версия формата и зоны профиля. Всё остальное программа сгенерирует сама: профиль, грунты, ряды уровней, отметки дороги.

```json
{
  "schemaVersion": 1,
  "meta": { "code": "12", "seed": 4512 },
  "geodesy": {
    "zones": {
      "BL": { "step": 20, "n": 4 },
      "LP": { "step": 20, "n": 25 },
      "R":  { "step": 15, "n": 10 },
      "PP": { "step": 20, "n": 15 },
      "BR": { "step": 20, "n": 6 }
    }
  }
}
```

Правила:

| Что | Как |
|---|---|
| Зоны профиля | Слева направо: `BL` — левый берег, `LP` — левая пойма, `R` — русло, `PP` — правая пойма, `BR` — правый берег |
| Берега | Не затапливаются ни при каком уровне ряда и при ВИУ. Только на них задаются отметки оси дороги (`tz.road`) |
| Число створов | Σn + 1. Граничный створ общий для соседних зон |
| `geodesy.z` | Отметки всех створов подряд. Если массив задан, его длина обязана совпадать с числом створов |
| Уровни в `hydro.series` | На оси перехода. Студент получает их пересчитанными на водомерный пост: превышения над нулём поста с учётом `post.offsetKm` |
| Ряд без суточных уровней | Можно задать только таблицей: `year`, `zMax`, `navDays`, `rsuPost` (уровни на посту для каждого t) |
| Значение `null` | Для `post.zero`, `viu.z`, `regime.zLo`, `regime.zHi` означает «вычислить» |

**Подсказка для нейросети:** приложите к запросу `schema/variant.schema.json` и этот раздел. Попросите вернуть только JSON по схеме и не заполнять `gen` и `library`.

## 2. Книга данных Excel

Во вкладке «Выдача» кнопка «Книга данных» выгружает текущий вариант в машиночитаемом виде. Каждый лист — одна таблица с заголовками в первой строке:

| Лист | Содержание |
|---|---|
| Описание | Правила заполнения |
| Параметры | Скалярные параметры: подпись, значение, единицы, ключ (путь в JSON) |
| Зоны | Шаг и число интервалов зон BL, LP, R, PP, BR |
| Профиль | Отметки по створам и комментарии |
| Дорога | Отметки оси ПЧ в характерных точках на берегах |
| Годы | Год, превышение П над нулём поста, длительность навигации, уровни при прекращении навигации на t суток (столбцы `t=…`) |
| ИГУ | Номер, код грунта, параметры генератора |
| Кровли | Отметки кровли ИГУ по створам |

Книгу можно заполнить или исправить и загрузить обратно («Открыть», файл .xlsx). **Пустая ячейка или пустой лист** означают: взять значение по умолчанию или сгенерировать. Например, если очистить листы «Профиль» и «Кровли» и поменять «Зоны», программа построит новый профиль и разрез под новые зоны.

Ключ параметра (столбец «Ключ») совпадает с путём в JSON, поэтому оба формата описывают одни и те же данные.
