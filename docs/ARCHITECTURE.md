# Архитектура BridgeCrossingApp

## Цепочка модулей

```
Журнал работы студентов → Варианты проекта → Расчёт уровня воды → Определение отверстия моста
                                                → Проектирование регуляционных сооружений → Вариантное проектирование моста
                 ↑
        Генератор задания (этап 1)
```

Модули связаны одним объектом — **вариантом задания**. Его формат описан в [VARIANT_FORMAT.md](VARIANT_FORMAT.md) и [`schema/variant.schema.json`](../schema/variant.schema.json). Вариант создаёт генератор или внешний источник (Excel, другая программа, нейросеть). Остальные модули его только читают; свои результаты они складывают в отдельные разделы.

## Принципы

1. **Модульность без сборки.** Каждый модуль — отдельная страница `apps/<модуль>/index.html`. Общий код лежит в `core/` и подключается обычными `<script>`. Страница открывается двойным щелчком, с GitHub Pages и без интернета. Те же файлы подключаются в Node.js для тестов (`tests/load.js`).
2. **Ядро без интерфейса.** `core/` — функции над объектом варианта; интерфейс только вызывает их и рисует.
3. **Выгрузка в редактируемые форматы на каждом этапе.** Общие сервисы:
   - `core/export.js` — оформленные документы Excel с живыми формулами для сверки;
   - `core/dataio.js` — машиночитаемый обмен: книга данных Excel, частичный JSON.
4. **Истина и то, что видит студент, разделены.** В варианте хранятся истинные значения: отметки дна, УВВ на оси, ВИУ, уклон. Студенческое представление вычисляется: глубины от уровня на дату изысканий, превышения над нулём поста, ВИУ над объектом, уклон задачей, перенос с водпоста.
5. **Воспроизводимость.** Генераторы детерминированы зерном `meta.seed` и производными от него зёрнами.
6. **Неполные данные допустимы.** Всё отсутствующее заполняется по умолчанию или генерируется (`dataio.fromPartial`, `schema.autofill`).

## Профиль: пять зон

| Зона | Ключ | Назначение |
|---|---|---|
| Левый берег | `BL` | Не затапливается. Здесь задаются отметки оси дороги |
| Левая пойма | `LP` | Нивелировка |
| Русло | `R` | Промеры глубин |
| Правая пойма | `PP` | Нивелировка |
| Правый берег | `BR` | Не затапливается. Здесь задаются отметки оси дороги |

Каждая зона задаётся шагом и числом интервалов; число створов производное (Σn + 1). В гидравлике берега относятся к поймам. Проверка выдаёт ошибку, если ВИУ или максимум ряда достигает берега.

## Шаблоны

Можно сохранить всё задание или отдельный раздел под уникальным именем. Разделы: геодезия (профиль, зоны, генератор, топография), гидрометеорология (вместе со справочником шероховатости), геология, ТЗ. Шаблоны хранятся в браузере; для переноса — экспорт и импорт файлом JSON.

## Изменения формата

Формат имеет номер версии `schemaVersion` (сейчас 1). При несовместимом изменении нужно увеличить номер и добавить в `schema.migrate()` перевод файлов предыдущей версии.
