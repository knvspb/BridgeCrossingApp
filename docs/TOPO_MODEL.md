# Модель топоповерхности (п. 17 плана)

Цель — правдоподобный учебный топоплан участка мостового перехода на равнинной реке. Сечение по оси дороги **в точности совпадает с профилем задания**: все искажения гасятся к оси в полосе ±12 % стороны квадрата.

## Уклон реки

| Что | Как понижается вниз по течению |
|---|---|
| Дно русла (всё сечение) | На **i·s**, где s — длина по оси русла от оси дороги. На изгибе s больше расстояния по долине |
| Пойма и коренные берега | С уклоном долины **iд = i·K**, где K — извилистость русла в пределах плана (длина русла / длина долины; при R = 0 K = 1) |
| Урез воды | Наклонный: **Zв(s) = Zизыск − i·s**. Вода на плане — всё, что ниже этого уровня (с допуском 2 см) |

На оси дороги (Y = 0) поправки равны нулю, поэтому сечение совпадает с профилем задания.

## Элементы рельефа

Набор форм опирается на типичное строение пойм равнинных рек: прирусловые валы, гривы и межгривные понижения, старицы — понижения от отчленившихся излучин. Источники: [«Пойма», Большая российская энциклопедия](https://bigenc.ru/c/poima-78bbbe); пособие, гл. 2.2–2.3, рис. 2.9–2.10.

| Элемент | Как моделируется |
|---|---|
| Старицы и понижения пойм из профиля | **Непрерывны вдоль всей долины**, до моста и после него. Их положение поперёк поймы плавно смещается: координата поймы σ (0 — подошва берега, 1 — бровка русла) деформируется как σисх = σ − a(y)·sin πσ. При \|a\| < 1/π отображение монотонно, края поймы неподвижны, a(0) = 0. Старица то приближается к руслу, то отдаляется, глубина меняется на ±20 %, но понижение нигде не обрывается |
| Коренные берега | Продолжение профиля за края с уклоном крайних участков; извилистая бровка; овраги поперёк долины (извилистые, глубина растёт от подошвы, у вершины сходит на нет) |
| Тренд поймы | Плавный переход от подошвы берега к бровке русла |
| Гривы и межгривья | Анизотропный шум, вытянутый вдоль русла |
| Прирусловые валы | Повышение до 0,6 м у бровок, затухающее на ширину русла |
| Серповидные озёра-старицы | Только вдали от оси дороги (её не пересекают), 1–3 на план |
| Русло | Сечение из профиля; в плане — дуга радиуса R. Долина смещается вслед за руслом, только когда русло подходит к краю поймы. На изгибе у вогнутого берега плёс, у выпуклого — отмель. Прежнее положение русла засыпано до уровня поймы |

При R = 0 река прямая, естественные формы по умолчанию выключены (их можно включить переключателем), но непрерывные понижения из профиля сохраняются.

## Отображение

- Полутоновая заливка по высоте с лёгкой отмывкой (свет с северо-запада); вода — голубым, по наклонному уровню.
- **Горизонтали не пересекаются.** Это изолинии **одной** сглаженной поверхности. Изолинии непрерывной функции не пересекаются ни между собой, ни сами с собой; проверено тестом на пересечение отрезков, в том числе после упрощения для DXF. Раньше каждая линия сглаживалась отдельно, сдвигалась на 10–15 м, и на крутых бровках, где горизонтали через 0,5 м стоят в 1–3 м друг от друга, соседние линии перехлёстывались. От этого подхода отказались.
  1. Сетка высот для изображения сглаживается гауссом σ: «нет» — 0, «среднее» — 0,7, «сильное» — 1,5, «очень сильное» — 2,5 шага сетки.
  2. **Минимальный радиус Rmin** (по умолчанию 25 м): где у горизонталей радиус меньше Rmin (по трём точкам на расстоянии ≈ Rmin/4 вдоль линии), сглаживание поверхности **локально усиливается** (карта сглаживания из 4 ступеней σ, до 6 шагов сетки), и горизонтали строятся заново, до 7 проходов.
  3. Поверхность уплотняется в 3 раза кубическим B-сплайном (непрерывная вторая производная), поэтому горизонтали плавные без доводки отдельных линий.
  - **Защищённые зоны** — русло (полоса 1,3 полуширины вдоль оси русла) и полоса у оси дороги (±4 % стороны плана). Там только базовое сглаживание: русло остаётся чётким, сечение у оси — близким к профилю.
  - Где радиус всё ещё меньше Rmin — это концы узких форм (озерки, ямы, понижения уже 2·Rmin). Обеспечить там Rmin можно только стерев форму. Их число показывается во вкладке.
  - Облако точек (CSV) не сглаживается: изображение и DXF — это генерализованное представление поверхности.
- Заливка воды и отмывка строятся по той же сглаженной поверхности, урез — изолиния этой же поверхности относительно наклонного уровня воды.
- **Неровности рельефа** (холмы, гривы, неровности дна) — сумма синусоид со случайными направлениями, без квадратной решётки (у «решёточного» шума на ровных площадках, например на правом берегу 129,00 м, нулевые линии давали прямоугольные фигуры). Формы генератора (овраги, озёра, гривы) не уже 2·Rmin.
- **Без длинных прямых.** Вне русла долина плавно смещается поперёк: волны длиной 0,6–0,9 и 0,3–0,45 стороны плана, амплитуда до 40 м (20 м при простом рельефе), разная для левой и правой стороны. Смещение монотонно (|∂D/∂x| < 0,5), равно нулю на оси дороги и в русле: при R = 0 река остаётся прямой. Прямые подошвы берегов и переломы профиля превращаются в пологие дуги радиусом порядка километра.
- **Неровности рельефа** (холмы, гривы, неровности дна) — сумма синусоид со случайными направлениями, без квадратной решётки (у прежнего «решёточного» шума на ровных площадках, например на правом берегу 129,00 м, нулевые линии давали прямоугольные фигуры).
- Утолщённые горизонтали — каждая пятая, с подписями вдоль линии. Урез — синей линией.
- Ось дороги, стрелка течения по оси русла, масштабная линейка.

## Выгрузка

- **CSV** — облако точек: «X;Y;Z» (десятичная запятая) или «x,y,z».
- **PNG** — изображение плана.
- **DXF** (AutoCAD R12, ASCII): каждая горизонталь — 3D-полилиния (POLYLINE с флагом 3D, вершины с Z = отметке горизонтали).

  | Слой | Содержание |
  |---|---|
  | `HOR_OSN` | Основные горизонтали |
  | `HOR_UTOLSH` | Утолщённые горизонтали |
  | `HOR_PODPIS` | Подписи (TEXT на отметке) |
  | `UREZ` | Урез воды: 3D, по наклонному уровню |
  | `OS_DOROGI` | Ось дороги: 3D по поверхности |
  | `OS_RUSLA` | Ось русла: 3D по уровню воды |
  | `RAMKA` | Граница плана |

  Координаты: X — вдоль оси дороги от левого края плана; Y — вверх против течения, как на экране. Линии упрощены по Дугласу — Пёккеру с допуском 2 см (пересечений не появляется — проверено). Файл проверен библиотекой ezdxf 1.3.4: читается без ошибок и исправлений, горизонтали распознаются как 3D-полилинии.

## Ограничения

Модель иллюстративная: она не воспроизводит русловые процессы и не годится для расчётов по плану. Расчёты ведутся по профилю.
